# 2026-09-25

## Hero section — portrait clipped at top (fixed)

Complaint: on the homepage hero, the portrait's head was cut off at the top; hero card + image
sat too high against the sticky header.

Root cause: the `.hero` section's top padding was `.65rem` (`.25rem` under 700px) while the
sticky header is `--header` = `5.4rem` (`4.7rem` mobile). The portrait also overhung the
`.hero-visual` box upward via `top: -2.15rem` (`-1.75rem` / `-1.25rem` in media queries), so
it intruded into the header band.

Files changed: `assets/css/styles.css` (5 values, no HTML changes)
- `.hero { padding: .65rem 0 3.8rem }` → `1.6rem 0 3.8rem`
- `.hero-portrait` desktop: `top: -2.15rem; height: calc(100% + 2.15rem)` → `-1.3rem`
- ≤1040px: `top: -1.75rem` → `-1.1rem`
- ≤700px: `top: -1.25rem` → `-.85rem`; `.hero { padding-top: .25rem }` → `.95rem`
